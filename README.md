# Mark — Developer Portfolio

A responsive, dark-themed, English-language developer portfolio.

## Customize
- Edit `index.html` to change the name, intro, location, and contact links.
- Edit `style.css` to change the visual design.
- Edit `script.js` to change the GitHub username. Public non-fork repositories are loaded automatically from the GitHub REST API.

## Run locally
Open `index.html` in a browser. For best results, use a local static server.

## Publish with GitHub Pages
1. Create a new **public** repository named `poseydonskyHub.github.io` (or another repository for a project site).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL appears in Settings → Pages.

You can also deploy the folder using Vercel or Netlify as a static site.

## Notes
- No private GitHub data is accessed.
- The projects section uses GitHub's public API and can be affected by API rate limits.
- Replace the GitHub contact link with a professional email address if you want clients to contact you directly.
- Keep project descriptions accurate and only claim skills you can demonstrate.
